## Spec Panel 2: Web 예약 등록 모달

| 항목 | 내용 |
|---|---|
| 플랫폼 | Web |
| 유저 | 비즈 |
| 화면명 | 유치원 홈 |
| 화면 경로 | 유치원 홈 |
| Case | 회원·반려견, 이용권, 날짜를 선택해 예약 또는 초과 예약을 등록한다 |

### Spec Description 1: 회원·반려견 선택

| Item | Content |
|---|---|
| Description Type | Input |
| Area | `반려견 또는 보호자 검색` |

- 보호자명 또는 반려견명으로 검색하고 결과를 선택한다.
- 선택을 변경하면 이용권과 날짜 선택을 초기화한다.
- 결과가 없으면 `검색 결과가 없습니다.`를 표시한다.

### Spec Description 2: 이용권 목록

| Item | Content |
|---|---|
| Description Type | Option |
| Area | 이용권 선택 |

- 예약 가능한 횟수가 남은 이용권만 표시한다.
- 최근 사용 이용권을 우선으로, 없으면 만료일이 빠른 이용권을 기본 선택한다.
- 이용권명, 선택 가능한 횟수, 유효기간을 표시하며 남은 횟수가 없으면 선택할 수 없다.
- 이용권을 변경하면 날짜 선택을 초기화한다.
- 이용권이 없어도 비즈 사용자는 초과 예약으로 등록할 수 있다.

### Spec Description 3: 예약 날짜

| Item | Content |
|---|---|
| Description Type | DatePicker |
| Area | 예약 날짜 달력 |

- 회원과 반려견을 선택하기 전에는 날짜를 선택할 수 없다.
- 현재 달 외 날짜, 마감된 날짜, 동일 반려견의 기존 예약 날짜는 선택할 수 없다.
- 여러 날짜를 선택하며 선택 날짜는 오름차순으로 관리한다.

### Spec Description 4: 등록

| Item | Content |
|---|---|
| Description Type | Button |
| Area | 등록 및 계속 등록 |

- 선택한 날짜별 예약을 생성한다.
- 연결된 이용권이 있으면 예약 가능 횟수를 날짜마다 1회 차감한다.
- 전체 예약 가능 횟수를 넘어도 비즈 사용자는 `초과 등록`으로 등록할 수 있고, 초과분과 이용권 미선택 예약은 이용권을 연결하지 않는다.
- 등록 후 `예약이 등록되었습니다.`를 표시하며, 이용권이 소진되면 `선택한 이용권을 모두 사용했습니다.`를 추가로 표시한다.
- `계속 등록`은 이용 가능한 이용권이 2개 이상일 때 활성화하고 회원·반려견을 유지한다.

## Policy Panel

### 예약 취소 이력

- affected scope: 예약 목록, 예약 상세, 이용권 사용 내역
- confirmed policy: 취소 예약은 제거하지 않고 취소 이력으로 보존하며, 예약 목록과 이용권 사용 내역에 표시한다.

### 초과 예약 및 이용권 미선택 예약

- affected scope: Web/App 예약 등록, 이용권 선택
- confirmed policy: 비즈 사용자는 이용권 잔여 횟수와 관계없이 초과 예약할 수 있으며, 이용권 없이도 예약할 수 있다. 초과분과 이용권 미선택 예약에는 이용권을 연결하지 않는다.
