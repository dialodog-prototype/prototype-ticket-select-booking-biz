# 이용권 선택 유치원 예약 정책 확인 필요 항목

## 정책 확인 필요 항목

1. 예약 취소 저장 방식
   - 확인된 사실: 프로젝트 범위 문서는 취소한 예약을 저장소에서 제거하도록 정의하지만, 현재 프로토타입은 예약을 `취소` 상태로 보존하고 사용 내역에도 표시한다.
   - 결정이 필요한 정책: 취소한 예약을 완전히 삭제할지, 취소 이력으로 보존할지 결정해 주세요.
   - 추천 기본값: 프로젝트 범위 문서에 맞춰 저장소에서 제거합니다. 이 경우 취소 이력이 필요한지 별도 정책을 추가로 정의합니다.

2. 이용권 횟수 초과 예약
   - 확인된 사실: 현재 프로토타입은 선택 이용권의 잔여 횟수를 넘는 날짜를 `초과 등록`으로 저장하며, 해당 예약에는 이용권을 연결하지 않는다.
   - 결정이 필요한 정책: 이용권 잔여 횟수를 초과하는 예약을 허용할지 결정해 주세요.
   - 추천 기본값: 허용하지 않고 `예약 가능한 횟수를 초과했습니다.`로 등록을 막습니다.

3. 이용권이 없는 회원의 예약
   - 확인된 사실: 현재 등록 검증은 이용권 미선택 시 `이용권을 선택해 주세요.`를 표시하며, 초과 등록 경로에서는 이용권이 연결되지 않은 예약이 생성될 수 있다.
   - 결정이 필요한 정책: 이용권이 없는 회원도 초과 예약으로 등록할 수 있는지 결정해 주세요.
   - 추천 기본값: 이용권 선택을 필수로 유지하고, 이용권이 없으면 예약 등록을 막습니다.
