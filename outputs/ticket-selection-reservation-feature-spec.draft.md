# 이용권 선택 유치원 예약 기능명세 초안

## 범위

회원과 반려견을 선택해 유치원 예약을 등록할 때 이용권을 선택하고, 선택 결과를 예약 상세와 이용권 사용 내역에서 확인하며 예약을 취소하는 흐름을 다룬다.

| 화면 경로 | 유치원 홈 |

| Item | Content |

- 예약은 반려견, 견종, 보호자 정보를 표시하고 취소할 예약을 선택할 수 있다.
- 등록된 예약이 없으면 `등록된 예약이 없습니다.`를 표시한다.

## Spec Panel 2: Web 예약 등록 모달

| 항목 | 내용 |
|---|---|
| 플랫폼 | Web |
| 유저 | 비즈 |
| 화면명 | 유치원 홈 |
| 화면 경로 | 유치원 홈 |
| Case | 회원·반려견, 이용권, 날짜를 선택해 예약을 등록한다 |

### Spec Description 1: 회원 검색 및 선택

| Item | Content |
|---|---|
| Description Type | Input |
| Area | 회원 검색 |

- `반려견 또는 보호자 검색`으로 회원과 반려견을 검색한다.
- 검색 결과에서 반려견을 선택하면 이용 가능한 이용권을 불러오고 기존 날짜 선택을 초기화한다.
- 결과가 없으면 `검색 결과가 없습니다.`를 표시한다.

### Spec Description 2: 이용권 선택

| Item | Content |
|---|---|
| Description Type | Option |
| Area | 이용권 목록 |

- 예약 가능한 횟수가 남은 이용권만 목록에 표시한다.
- 최근 사용한 이용권이 있으면 해당 이용권을 우선 선택하고, 없으면 만료일이 빠른 이용권을 기본 선택한다.
- 각 옵션에 이용권명, 선택 가능한 횟수, 유효기간 정보를 표시한다.
- 선택 가능한 횟수가 모두 소진된 이용권은 선택할 수 없다.
- 이용권을 변경하면 선택 날짜를 초기화한다.
- 이용 가능한 이용권이 없으면 `사용 가능한 이용권이 없습니다.`를 표시한다.

### Spec Description 3: 예약 날짜

| Item | Content |
|---|---|
| Description Type | DatePicker |
| Area | 예약 날짜 달력 |

- 회원과 반려견을 선택하기 전에는 날짜를 선택할 수 없다.
- 현재 달이 아닌 날짜, 마감된 날짜, 동일 반려견의 기존 예약 날짜는 선택할 수 없다.
- 여러 날짜를 선택할 수 있고 선택한 날짜는 오름차순으로 관리한다.

### Spec Description 4: 예약 등록

| Item | Content |
|---|---|
| Description Type | Button |
| Area | 등록 및 계속 등록 |

- 회원·반려견, 이용권, 예약 날짜가 유효할 때 `등록` 버튼을 활성화한다.
- 선택 날짜별 예약을 생성하고 선택 이용권의 예약 가능 횟수를 1회씩 차감한다.
- 선택 날짜 수가 전체 예약 가능 횟수를 넘으면 `초과 등록`으로 표시한다.
- 등록 후 `예약이 등록되었습니다.`를 표시하고, 선택 이용권이 소진되면 `선택한 이용권을 모두 사용했습니다.`를 추가로 표시한다.
- `계속 등록`은 이용 가능한 이용권이 2개 이상일 때만 활성화하며 선택한 회원과 반려견을 유지한다.

## Policy Panel

### 예약 취소의 저장 결과

- affected scope: 예약 상세, 예약 목록, 이용권 사용 내역
- confirmed policy: 프로젝트 범위 문서는 취소 시 저장된 예약을 제거한다고 정의한다.
- needs confirmation: 현재 프로토타입 구현은 예약을 제거하지 않고 `취소` 상태와 취소 일시를 저장하며, 사용 내역에도 취소 항목을 표시한다. 최종 동작을 하나로 확정해야 한다.

### 이용권 선택 및 초과 예약

- affected scope: Web/App 예약 등록, 이용권 선택
- confirmed policy: 예약 가능한 횟수가 남은 이용권만 선택 목록에 보이며, 기본값은 최근 사용 이용권 우선·그 외 만료일 빠른 순서다.
- needs confirmation: 선택 이용권의 횟수를 넘는 날짜도 `초과 등록`으로 예약할 수 있다. 초과 예약을 허용할지와 이용권 미연결 예약의 처리 기준을 확정해야 한다.
